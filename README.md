# Parama Closing & Operations PWA

Standalone Parama Cafe closing and operations app based on the Santara V4.3.9 engine.

This repository is intentionally separate from `santara-closing-pwa`.

## Current status
- Parama V1 scaffold
- Engine baseline: Santara V4.3.9
- Master data: Parama-specific
- Do not deploy until Google Apps Script Spreadsheet ID / deployment configuration is set for Parama.

## Important
The core operational algorithms are preserved from the supplied Santara V4.3.9 source. Changes should be limited to Parama branding/configuration and Parama master data unless explicitly approved.
